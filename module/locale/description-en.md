# Resource Grid Overlay

**The resource grid now lives in Map Editor Improvements** (from version 1.0.65), in its
"Resource grid" settings group. Use that module instead of this one. While both are turned on,
Map Editor Improvements leaves the grid to this module. Settings are not taken over: if you
changed this module's settings, set them again there.

Shows the AI's resource grid, castle-rotation boundaries and iron mine footprint to help place resources in the map editor.
